包税服务说明

什么是包税服务？

包税服务（DDP）是指在提交包裹时预先支付关税费用，由POKO统一处理清关和缴税事宜。您无需在收货时再向海关或物流商支付任何税费。

包税 vs 不包税

对比项 包税 不包税
费用 运费已含关税，总价固定 运费 + 收货时可能产生的关税
清关 POKO全权处理，无需您操作 可能需要您配合提供资料、自行缴税
成本 可控，支付时即锁定总费用 不可控，关税金额由海关决定
适合场景 高价值商品、敏感品类、希望省心 低价值商品、公司商业报关

如何计费？

  • 包税费用 = 包裹申报价值 × 当前线路包税率
  • 包税率因目的国和物流线路不同而有所差异
  • 提交订单时系统自动计算，费用在收费明细中单独展示

建议开启包税的场景

  • 🎯 高价值商品：电子产品、奢侈品等，关税可能较高
  • 🎯 敏感品类：带电品、液体等，被查验概率更高
  • 🎯 不熟悉目的国关税政策：省心省力，避免意外支出

温馨提示

  • 包税服务覆盖正常清关产生的关税和增值税
  • 如因申报信息不实或商品违反目的国法规导致的额外费用，不在包税范围内
  • 部分国家/地区有免税额度，低价值包裹可不选包税

保价服务说明

保价费率

  • 保价金额 ≤ ¥1000：保价费 = 保价金额 × 3%
  • 保价金额 > ¥1000：保价费 = 保价金额 × 5%
  • 最低保价费 ¥5

理赔规则

  • 货物在运输途中丢失：按保价金额全额赔付
  • 货物在运输途中破损：不在赔付范围内
  • 理赔周期：提交理赔申请后 7-15 个工作日内完成审核

免责条款

  • 因不可抗力（自然灾害、战争等）导致的损失不赔付
  • 因海关查验扣押导致的损失不赔付
  • 因申报信息不实导致的损失不赔付
  • 违禁品、易碎品（未特殊包装）不在保价范围内

温馨提示

POKO会根据包裹预估重量收取预估运费，包裹最终运费以承运方核定的重量为准。

关于运费差额

  • 预付大于实际：如若产生差额，我们会在打包后的7天内退还多余部分金额
  • 预付小于实际：如若承运方核定的重量超过预估重量，则需要您进行补款

为什么会有差额？

  • 商品实际重量与预估可能有轻微差异
  • 打包后可能添加防护材料导致重量增加
  • 不同线路对重量计算方式可能不同
