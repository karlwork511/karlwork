设计说明（不产出到正式页面）
多商品订单顶部为商品TAB横滑切换，一个商品一个TAB；订单编号栏、买手留言、订单信息、费用明细为订单维度，不随TAB切换
增值服务区块位于选中商品卡片内下方（截图红框位置），随TAB切换联动，仅展示该商品购买的增值服务；未购买则不展示
服务行展示：服务名称、实付金额、用户状态（处理中/已完成/已取消）
用户状态映射：待支付/待推送/已推送 → 处理中（黄）；已完成 → 已完成（绿）；已取消 → 已取消（红）
按照片数量计费的服务：处理中展示「查看拍照需求（N条）」；已完成展示照片缩略图+「查看需求及照片（N）」；其他计费方式且用户填写了备注：展示「查看备注」；未填备注则不展示入口
仓库回传的照片无法区分属于哪条需求，照片与需求不建立对应关系；弹窗内分区展示：上方为拍照需求列表（①②③），下方为仓库回传照片墙，点击照片进入全屏查看
全屏查看器：左右滑动切换照片，左上角序号N/M，右上角关闭；服务行缩略图与弹窗照片墙均可点击进入（正式版支持双指放大）
处理中/已取消的服务不展示照片；已取消服务的退款金额展示在入口行，需求/备注内容仍可查看
本页仅展示增值采购服务（商品维度）；入库包裹服务在包裹详情页展示
费用明细新增「增值服务费」行，为下单时实付的增值服务合计；服务取消后的退款在服务状态处展示，不回改订单金额
本页只读展示，不提供购买/取消入口；购买在下单流程完成
