# POKO 代购集运平台 — 会员管理模块

## 模块概述

会员管理模块是代购集运 SaaS 平台的基础模块，面向租户运营人员提供 C 端会员的全生命周期信息管理。

核心能力：
- 会员注册（邮箱注册 + 第三方快捷登录）与服务平台实时同步
- 会员列表查询、详情查看、启用/禁用、同步重试
- 代购订单、提包单、积分、优惠券、余额、消费记录、售后等业务数据详情展示
- 收货地址管理与实名认证（台湾易利委接口）

## 会员列表页

- 筛选：关键词搜索（会员ID/邮箱/昵称）、会员状态、同步状态、注册端口、注册时间范围
- 列表字段：会员ID、集运会员ID、租户ID、昵称、邮箱、注册端口、会员状态、同步状态、余额、累计代购单、累计提包单、注册时间、最后登录时间、运营备注（点击弹窗编辑）、操作
- 运营备注列：有内容时显示文本预览（超长截断省略），无内容时显示 `-`，点击均打开编辑弹窗

## 会员详情页

**固定头部**：头像、昵称、邮箱、会员ID、会员状态标签、操作按钮（启用/禁用、同步重试）

**基本信息区域**（始终展示，非 Tab）：租户ID、集运会员ID、注册时间、最后登录、国家、语言、默认仓库、默认币种、注册端口、同步状态详情、运营备注

**数据概览横幅**（左右分栏）：
- 消费概览：累计代购单、累计提包单、累计消费金额、仓库待提包、代购售后金额、代购售后次数
- 资产概览：当前余额、可用积分、累计积分、已使用积分、未使用优惠券、已使用优惠券、已过期优惠券

**9 个 Tab**：
1. 代购订单
2. 提包单
3. 余额明细
4. 积分明细
5. 优惠券明细
6. 消费记录
7. 售后记录
8. 第三方授权（Line/微信/Facebook/Google/抖音/TikTok）
9. 收货地址（含实名认证）

## 关键业务规则

- 会员双状态模型：status（正常/禁用，人工控制）+ sync_status（未同步/已同步/同步中/同步失败，系统控制）
- 所有会员必须有邮箱，不允许无邮箱会员
- 登录时仅校验 status，不校验 sync_status
- 注册同步失败自动重试 3 次（3秒/30秒/5分钟），运行时异常不自动重试
- 同 provider 拒绝换绑，必须先登录原账号解绑
- 数据主从原则：会员信息以代购平台为准，服务平台不反向同步
